# maki-genui

Generative UI for [maki](https://github.com/yonatanofek101/maki): the model calls `ui_render` /
`ui_update` / `ui_close` with a declarative component spec, the plugin renders it as real interactive
terminal UI inside the chat (forms, pickers, tables, diffs, dashboards) and reports back what the user
did. This README is a placeholder; the full documentation lands with the first release.
